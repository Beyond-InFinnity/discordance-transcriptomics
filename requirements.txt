# NOT LISTED HERE, DELIBERATELY: torch
#
# GPU acceleration is optional — nothing in the pipeline requires it, and the
# only consumer is src/utils/compute.py, used by analyses not yet on the
# critical path. More importantly it CANNOT be pinned repo-wide, because the
# machines need mutually exclusive builds:
#
#   torch 2.9.1+cu128  -> sm_70 … sm_120   RTX 5050 (sm_120) works, 1080 Ti does not
#   torch 2.5.1+cu121  -> sm_50 … sm_90    1080 Ti (sm_61) works, RTX 5050 does not
#
# A single pin would silently disable a GPU on one host — which is exactly what
# happened: cu121 was installed by hand, chosen from memory rather than from the
# hardware, and left the workstation's RTX 5050 unusable for a day.
#
# Install per machine, choosing the index from the card, and check
# torch.cuda.get_arch_list() against the device's compute capability:
#
#   workstation (RTX 3070 + RTX 5050)  uv pip install torch --index-url .../cu128
#   laptop      (RTX 3070 Laptop)      uv pip install torch --index-url .../cu128
#   claude-machine (GTX 1080 Ti)       uv pip install torch --index-url .../cu121
#
# See CLAUDE.md §4.2 for what a GPU is and is not worth here: fp32 is ~44x the
# CPU, fp64 is ~1.1x and therefore pointless on every card we own.
# ---------------------------------------------------------------------------
